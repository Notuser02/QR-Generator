QR Code Generator & Designer

A lightweight, web-based tool that lets you create, customize, and download QR codes in real time right from your browser—no account or backend required!

What is this project?

This project is an interactive web application built with React and Tailwind CSS. It allows anyone to generate custom QR codes for websites, plain text messages, contact information, or Wi-Fi passwords.

Everything runs directly inside your web browser, making it fast, private, and secure.

How It Works:-

Select a Type: Choose what kind of information you want to share:

 URL: Web links and landing pages.

 Text: Any plain text message or note.

 Email: Pre-filled email addresses, subjects, and body text.

 Phone: Direct dial phone numbers.

 Wi-Fi: Automatic network connecting details (Network name, password, encryption type).

Customize the Look:-

Change the foreground and background colors.

Adjust the size to fit your needs.

Pick from quick design presets (e.g., Dark Mode, High Contrast).

Adjust Error Correction to make the code easier for phone cameras to scan.

Live Safety Check:-

As you change colors, the app automatically checks the contrast between the background and foreground. If the contrast is too low, it displays a Low Contrast Warning so you don't accidentally create an unscannable QR code.

Download & Save:-

Download your design as an Image (PNG) or vector graphics (SVG).

Your recent designs are automatically saved in your browser's local history so you can reload them anytime!

Key Features:-

 Instant Preview: Changes update immediately on screen as you type or adjust settings.

 Built-in Dark Mode: Toggle between light and dark themes for comfortable viewing.

 History Persistence: Saves your last generated codes in localStorage so they stay even if you refresh the page.

 Mobile Friendly: Works smoothly on phone screens, tablets, and desktop browsers.

 100% Client-Side: No data is sent to external servers; your data stays entirely in your browser.

Built With:-

React: For managing the interactive user interface and live updates.

Tailwind CSS: For clean, modern, and responsive styling.

Lucide React: For icons.

react-qr-code: For generating the visual QR code structures.
